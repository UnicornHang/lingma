## Brand & Style

The design system caters to high-intensity creative writing, narrative architecting, and autonomous multi-agent co-authoring workflows. It is built for novel writers, worldbuilders, and creative teams operating within immersive, multi-pane desktop environments (optimized for 1920×1080 resolution). 

The visual signature blends **Modern Editorial Minimalism** with **Luminous Glass & Precision Productivity**. The interface must avoid cognitive exhaustion over 8+ hour continuous sessions by prioritizing eye comfort, serene nature-derived hues, pristine legibility, and crystal-clear information density.

### Emotional Signature
- **Clarity & Respiration:** Wide gutters, subtle structural dividers, and pale jade-tinted surfaces evoke freshness, focus, and quiet inspiration.
- **Intelligent Fluidity:** Real-time AI agent suggestions and multi-threaded narrative nodes feel responsive, agile, and transparent without jarring or aggressive visual interruptions.
- **Exclusion Principle:** Under no circumstances should purple, violet, indigo, or blue-violet accents appear in any state (neutral borders, AI badges, glows, or active indicators).

## Colors

The palette leverages restorative teal, emerald, and vibrant sky cyan over ultra-clean, soothing pale grounds. It completely banishes muddy greys and purple-spectrum hues.

### Primary Spectrum: Teal & Emerald
- **Primary Main (`#0D9488`):** Deep energetic teal. Anchors primary calls-to-action, narrative state checkpoints, and active workspace focus.
- **Primary Vibrant (`#059669`):** Fresh emerald accent for successful generation, AI sync confirmations, and creative pulse badges.
- **Primary Tint Surface (`#F0FDF4` / `#CCFBF1`):** Soft spearmint and seafoam base coats for active blocks and selected manuscript lines.

### Secondary Spectrum: Sky & Horizon
- **Secondary Main (`#0284C7`):** Vivid celestial sky blue. Represents auxiliary AI agents, narrative timeline threads, entity relations, and deep-link citations.
- **Secondary Tint (`#E0F2FE`):** Soft clear-sky backdrop for floating parameter toolbars, agent avatar badges, and secondary action hover states.

### Neutral & Canvas Palette
- **Canvas Base (`#F8FAFC`):** Crisp daylight slate-white that preserves eye health.
- **Paper Canvas (`#FFFFFF`):** Pure white for active editor sheets, narrative node cards, and modal sheets.
- **Text Headings (`#0F172A`):** Deepest ink obsidian for razor-sharp typographic contrast.
- **Text Body (`#334155`):** Softened graphite for continuous long-form manuscript reading.
- **Borders & Dividers (`#E2E8F0`):** Fine hairline separators, optionally infused with a 5% teal wash (`#E6F4F1`).

## Typography

The type system is powered by **Plus Jakarta Sans**, offering a harmonious union of geometric precision and organic warmth. It excels in dual roles: dense UI metric dashboards and fatigue-free long-form novel composition.

### Manuscript Reading Rules
- **Drafting Pane (`body-xl` / `body-lg`):** Manuscript prose is explicitly tuned with generous line-height (`1.75x` to `1.8x`) to ensure visual rhythm during extended sessions. Optimal line lengths should be maintained between 65 to 80 characters per line.
- **Agent Output & Metadata (`body-md` / `label-sm`):** System suggestions, context memory tokens, and entity tags utilize balanced, tighter vertical metrics for maximum scan efficiency.

## Layout & Spacing

The layout is built for 1080p desktop multi-column command centers while retaining fluid modularity across screen widths.

### Workspace Spatial Architecture (1920×1080 Desktop)
- **Triple-Dock Modular Grid:**
  - **Left Navigation & World Directory:** Fixed 280px or collapsible to 64px icon bar. Houses character codices, plot timelines, and chapter hierarchies.
  - **Central Authoring Stage:** Fluid pane with a constrained reading container (max-width 860px) centered to prevent horizontal neck strain.
  - **Right Agent Multi-Desk:** 380px–460px responsive dock. Houses co-author LLM agents, dynamic consistency checkers, and style analyzers.
- **Density Grid:** Uses an 8px base rhythm (`space-xs` = 4px, `space-sm` = 8px, `space-md` = 16px, `space-lg` = 24px, `space-xl` = 32px) for exact pane alignment and modular docking.

## Elevation & Depth

Visual hierarchy rejects muddy drop shadows in favor of **Luminous Ambient Backdrops** paired with **Teal-Infused Hairline Outlines**.

### Elevation Hierarchy
- **Level 0 (Canvas):** Pure daylight base (`#F8FAFC`). No shadow, no outline.
- **Level 1 (Panels & Editor):** Surface (`#FFFFFF`) with a subtle `1px solid #E2E8F0` border and an ultra-diffused hint of emerald atmosphere: `0 1px 3px rgba(13, 148, 136, 0.04), 0 1px 2px rgba(15, 23, 42, 0.03)`.
- **Level 2 (Floating Palettes & Agent Cards):** Surface (`#FFFFFF`) with border `1px solid #CCFBF1`, lifted by `0 10px 25px -5px rgba(13, 148, 136, 0.08), 0 8px 10px -6px rgba(2, 132, 199, 0.04)`.
- **Level 3 (Modal Dialogs & Context Overlays):** Semi-opaque frosted backdrop blur (`backdrop-filter: blur(12px) saturate(180%)`) with background `rgba(255, 255, 255, 0.88)` and border `1px solid rgba(13, 148, 136, 0.20)`. Shadow: `0 20px 35px -10px rgba(15, 23, 42, 0.12)`.

## Shapes

The interface employs a balanced `roundedness: 2` (base radius of 8px / 0.5rem), striking an equilibrium between clean modern software tooling and human-friendly softness.

### Corner Radius Mapping
- **Interactive Controls (Inputs, Buttons, Dropdowns):** `rounded-md` (8px).
- **Cards, Docks, & Floating Panels:** `rounded-lg` (16px) to maintain gentle structural framing.
- **Status Chips, Pill Selectors, & Agent State Badges:** `rounded-full` (9999px) to communicate modular dynamic entities.

## Components

### Buttons
- **Primary Button:** Gradient surface from `#0D9488` to `#059669`. White text (`#FFFFFF`), `font-weight: 600`. Subtle glowing hover state: `0 4px 14px rgba(13, 148, 136, 0.35)`.
- **Secondary Button:** Solid `#E0F2FE` base with `#0284C7` text. Hover shifts to `#BAE6FD`.
- **Tertiary / Ghost Button:** Transparent background, text `#334155`. Hover transitions to `#F0FDF4` with `#0D9488` text.

### Chips & Entity Tags
- **Plotline / Node Chips:** Soft pill shape. Background `#F0FDF4`, border `1px solid #A7F3D0`, text `#065F46`.
- **Agent Identifier Badges:** Background `#F0F9FF`, border `1px solid #BAE6FD`, text `#0369A1` with a pulsing 6px bright cyan dot.

### Lists & Navigation Tree
- **Manuscript Directory Items:** 36px height, 8px horizontal padding, rounded corners (8px). Active item features `#CCFBF1` background, `#0F766E` text, and a 3px vertical accent bar on the left in `#0D9488`.

### Input Fields & Editor Settings
- **Text Inputs & Search:** Background `#FFFFFF`, border `1px solid #CBD5E1`, text `#0F172A`. On focus: border shifts to `#0D9488` accompanied by a 3px ring of `rgba(13, 148, 136, 0.15)`.
- **Prompt Composer Area:** Framed in `#E2E8F0` with floating quick-action pills along the bottom edge for character perspectives, tone toggles, and branch forks.

### Checkboxes & Radios
- **Selection State:** Checked state fills with `#0D9488` showing a crisp white glyph. Hover shows a ring tint of `rgba(13, 148, 136, 0.12)`. Avoid generic blue or indigo checks.

### Cards & Workspace Panels
- **Agent Activity Card:** Card body in pure white `#FFFFFF` with top accent border (2px) in `#0284C7`. Contains clear metadata separation, streamable markdown prose tokens, and inline rejection/acceptance controls.
- **Narrative Codex Card:** Enclosed in `1px solid #E2E8F0`, transitioning on hover to `1px solid #5EEAD4` with subtle translateY(-2px) elevation.
